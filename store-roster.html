One-time setup steps
  1. In Entra ID → App registrations, create an app (SPA platform). Add this page's URL as a redirect URI.
  2. Under API permissions add Microsoft Graph delegated Sites.ReadWrite.All (and grant admin consent).
  3. Copy the Application (client) ID and Directory (tenant) ID into the fields above.
  4. On the chosen SharePoint site, create a custom list (e.g. StoreRoster) with a multi-line text column named Data.
  5. Paste the site URL + list name, save, then Sign in and use Load / Save.
